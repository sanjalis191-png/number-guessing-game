# Internship Submission Notes

Task: Number Guessing Game

Technologies:
- Python 3
- Command Line Interface (CLI)
- Python random module

Main Python concepts:
- Variables
- input()
- int()
- random.randint()
- if / elif / else
- while loops
- Functions
- try / except
- Attempt counting

The computer selects a random number between 1 and 100. The user guesses
until the correct number is found. The program gives high/low hints,
counts attempts, handles invalid input, and supports another round.

Run with:
python main.py
